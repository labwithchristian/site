{{- /* Site override of Blowfish's heading hook. Two departures from the theme: 1. Classes set with Goldmark attributes ("## Education {.h-minor}") are kept, which the theme's version drops. 2. The hover anchor is a drawn mark rather than a "#" glyph, and it is positioned by `.heading-anchor` in 10-typography.css rather than by utility classes. The theme sized the glyph with the heading's own font-size inside a fixed 24px box, so the gap to the text ran from 0.6px on a large heading to 15.1px on the small mono eyebrow. A fixed box with the icon right-aligned puts every anchor the same distance from its heading, whatever the size. The mark is a chef's toque, which keeps the site on one metaphor: the pot in the nav, the pan in the search icon, the pans on the pipeline badges. Its stroke is a little heavier than the 1.8 the other icons use, because this one renders as small as 14px and the finer weight thins out there. */ -}} {{ $anchor := anchorize .Anchor }} {{- $class := "relative group" -}} {{- with .Attributes.class }}{{ $class = printf "%s %s" $class . }}{{ end -}} {{ .Text | safeHTML }} {{ if .Page.Params.showHeadingAnchors | default (.Page.Site.Params.article.showHeadingAnchors | default true) }} {{ end }}
